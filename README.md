# VitalFlow — React + Tailwind CSS

A responsive healthcare website recreation inspired by the VitalFlow Framer template. Built with React, Tailwind CSS, React Router, Lucide icons and Framer Motion.

## Run locally
1. Install Node.js (LTS) if it is not installed.
2. Extract this ZIP.
3. Open the extracted `vitalflow-react` folder in VS Code.
4. Open Terminal → New Terminal and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Included routes
- `/` Home
- `/about` About
- `/services` Services
- `/doctors` Doctors
- `/blog` Blog
- `/contact` Contact
- `/careers` Careers
- `*` Custom 404 page

## Notes
- Tailwind CSS is configured through `tailwind.config.js` and `postcss.config.js`.
- React Router provides client-side navigation.
- Framer Motion adds entrance and hover animations.
- Photos use remote Unsplash image URLs, so internet access is needed to load them.
- This is an independent recreation for learning purposes, not the original Framer source code. Some exact spacing, images, and motion timing may differ from the reference site.
